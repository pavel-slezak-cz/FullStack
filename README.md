# Události – Fullstack aplikace

Tato aplikace slouží pro správu událostí a hlasování o nejvhodnějším termínu.

## 🧱 Architektura

Projekt je rozdělen do dvou částí:

- **`client/`** – frontend v React + TypeScript + Vite
- **`server/`** – backend v Node.js + Express + TypeScript

## 🖥️ Spuštění

### Backend (server)
```bash
cd server
npm install
npm run dev
